# F/x/'s Spring Types

These are the types used in my backend spring template that can be used or distributed as needed. These types are pretty much useless outside any other context. 

## Usage

To use these types, you must be authenticated to the registry of [npm.fofx.zip](https://npm.fofx.zip) and have access to the `@fofx/spring-types` package. You can install it using npm or yarn:

```bash
npm install @fofx/spring-types
```

or

```bash
yarn add @fofx/spring-types
```

## Contributing

Contributions to this package are welcome but there is one strong rule.

These types **must** exist in the `main` branch of the spring template repository. If you want to add a type, you must add it to the main branch of the spring template repository and then update this package to include the new type.
